# MP Modas

Site institucional e vitrine digital da MP Modas Concept.

## Sobre o projeto

Apresenta a loja, as seleções masculina e feminina, as marcas, localização e canais de contato.

## Stack

- HTML5
- CSS3
- JavaScript Vanilla
- GitHub Pages

## Características

- Responsivo e mobile-first
- Acessibilidade básica
- Menu mobile acessível
- Carrossel com swipe
- Imagens WebP otimizadas
- SEO técnico básico

## Páginas

- Home
- Masculino
- Feminino
- Marcas
- A Loja

## Execução local

```bash
python -m http.server 5500
```

Acesse `http://localhost:5500/`.
